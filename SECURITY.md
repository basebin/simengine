## Reporting a Vulnerability

Use this section to tell people how to report a vulnerability.

Report security vulnerabilities by emailing the maintainers at [your-email@example.com] or by creating a private issue on GitHub. We will respond within 48 hours and provide updates on the status of the report. If accepted, we will work on a fix and release it as soon as possible. If declined, we will provide a detailed explanation.
